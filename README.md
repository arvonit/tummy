# Tummy

Tummy is an iOS social media app for ranking restaurants, bars, bakeries, cafes, and dessert spots 
with friends. You rank places by answering a few "Which did you like more?" comparisons and each 
score comes from its rank on a bell curve, so most places land around 7.5–8.5 and a 10 is genuinely 
rare. Unlike Beli, which spreads scores evenly, a high score means something, and Tummy is a native
Swift app, so lists, maps, and transitions stay smooth.

The iOS app lives in `app/`, and the design docs and build plans are in [docs/](docs/README.md).
